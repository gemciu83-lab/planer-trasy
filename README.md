# Planer Trasy

Autorski planer tras rowerowych Jakuba.

## Jak uruchomic lokalnie

Otworz `index.html` w przegladarce.

## Jak wrzucic na GitHub Pages

1. Wejdz na https://github.com i zaloguj sie.
2. Kliknij `New repository`.
3. Nazwa np. `planer-trasy`.
4. Wybierz `Public`, jesli link ma dzialac dla kazdego.
5. Kliknij `Create repository`.
6. Kliknij `uploading an existing file` albo `Add file` -> `Upload files`.
7. Wrzuć wszystkie pliki z tego folderu, nie sam folder.
8. Kliknij `Commit changes`.
9. Wejdz w `Settings` -> `Pages`.
10. W `Build and deployment` ustaw `Deploy from a branch`.
11. Branch: `main`, folder: `/root`.
12. Kliknij `Save`.
13. Po chwili link bedzie w stylu: `https://twoj-login.github.io/planer-trasy/`.
